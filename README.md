# ML-Semester-Project
Group machine learning semester project - Fall 2026






## Dataset

- Source: Stationery dataset by Lalaworkspace
- Version: 7
- License: CC BY 4.0
- Download: https://universe.roboflow.com/lalaworkspace/stationery-l7qrn/dataset/7

### Download instructions
Select YOLOv8 → Download dataset → Continue.
Choose the ZIP download and extract it on your computer.

### Dataset size
- Training: 2,268 images
- Validation: 111 images
- Test: 206 images
- Total: 2,585 images, including augmented images

### Class IDs
- 0: eraser
- 1: pencil
- 2: pencil sharpener
- 3: ruler

### Package inspection target
A complete package contains 2 pencils, 1 eraser, and 1 ruler.

### Current status
Dataset downloaded. Annotation quality and overlap between
training, validation, and test sets still need checking.
